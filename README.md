Este proyecto parte del mundo de ejemplo ure.wbt de Universal Robots en Webots, el cual incluye un robot SCARA.

En su versión original, el robot se encarga de apilar objetos iguales, específicamente latas.

La modificación propuesta consiste en ampliar esta funcionalidad para que el robot pueda clasificar dos tipos diferentes de objetos que irán llegando, utilizando sensores y cámaras para identificarlos y separarlos correctamente.
